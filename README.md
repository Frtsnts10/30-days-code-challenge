# 🚀 30 Days Code Challenge

One fully working, real-world project every day for 30 days, each in its own folder, across many languages. The projects start small (automation scripts) and get bigger week by week, ending with full end-to-end applications.

Every project here is:

- ✅ **Ready to use**: it runs as-is, with no placeholders
- 🛡️ **Robust**: it handles bad input, edge cases and network failures with friendly error messages
- 🎨 **Polished**: modern, responsive UIs for web/GUI apps, and clean, coloured output for CLIs
- 📖 **Documented**: each folder has its own README with prerequisites, install steps and example runs
